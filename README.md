Atliq Hardware — Sales Analysis | Excel
📌 Project Overview

This project presents a sales analysis of Atliq Hardware using Microsoft Excel.

The analysis focuses on understanding sales performance across countries, products, new product launches, customers, markets, regions and divisions, with a comparison of sales performance across 2019, 2020 and 2021.

The objective is to organize the available sales data into meaningful reports that can support business performance analysis and decision-making.

🎯 Business Objective

The key objective of this analysis is to understand:

Which countries are contributing the highest sales?
Which products are among the top performers?
How have sales changed across 2019, 2020 and 2021?
How are newly introduced products performing?
Which customers, markets and regions contribute to sales performance?
Which products show significant changes in sales compared with the previous year?
